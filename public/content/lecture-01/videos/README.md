# Бірінші дәрістің бейнематериалдары

Осы қалтаға MP4 немесе WebM файлдарын жүктеңіз.
Файлдар сайттың «Бейнематериалдар» бөлімінде автоматты пайда болады.
Файл атауы материалдың атауы ретінде көрсетіледі.

GitHub: Add file → Upload files → Commit changes.
Үлкен видеоларды YouTube-қа орналастырып, сілтемесін бір деңгей жоғарыдағы materials.json файлына қосыңыз.

Толық нұсқаулық: репозиторий түбіріндегі MATERIALS_KZ.md.
