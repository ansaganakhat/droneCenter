# Бірінші дәрістің презентациялары

Осы қалтаға PDF, PPT, PPTX немесе HTML файлдарын жүктеңіз.
Файлдар сайттың «Презентация» бөлімінде автоматты пайда болады.
Файл атауы материалдың атауы ретінде көрсетіледі.

GitHub: Add file → Upload files → Commit changes.
PDF сайт ішінде ашылады. PowerPoint файлы жүктеледі.
Сілтемелер мен жеке атауларды бір деңгей жоғарыдағы materials.json файлына қосуға болады.

Толық нұсқаулық: репозиторий түбіріндегі MATERIALS_KZ.md.
